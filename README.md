# SWYNEX – Data Cleaning & Preparation

## Project Overview
This project focuses on cleaning and preparing a public Students Performance in Exams dataset for analysis using Python and Pandas.

## Tasks Performed
- Inspected the dataset and its column data types.
- Checked for missing values and duplicate records.
- Removed duplicate rows where present.
- Handled missing numerical and categorical values where necessary.
- Standardized whitespace in text columns.
- Verified the cleaned dataset and exported it as a CSV file.

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Files Included
- `data_cleaning.ipynb` – Data cleaning code and verification.
- `cleaned_students_performance.csv` – Cleaned dataset.

## Result
The dataset was inspected, cleaned where necessary, and exported for further analysis. Actual changes and final row counts are documented in the notebook output.
